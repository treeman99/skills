# 폐기 규칙

`rules.md`에서 내린 블록을 이유와 함께 보존한다. 지우지 않는 이유는 **부활 방지**다 — 한 번 기각한
규칙이 몇 달 뒤 다른 문장으로 다시 후보에 오르는 일이 실제로 생기고, 그때 "왜 버렸는지"가 남아
있어야 같은 판단을 반복하지 않는다.

승격 심사에서 후보가 이 파일의 내용과 겹치면 사용자에게 그 사실을 먼저 알린다.

형식:

```text
### R-0NN · scope: <scope> · 폐기 YYYY-MM-DD · 최종 적중 N
<원래 규칙 요지 한 줄>
폐기 사유: <예산 초과 / 적중 0 / 게이트가 대체 / 사실 무효>
```
